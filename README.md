# Freebox RTS Shutters

Add-on pour l'intégration Freebox du cœur de Home Assistant : expose en `cover` les volets
RTS (catégorie Freebox Home `basic_shutter`) que le cœur ne gère pas.

- L'intégration Freebox du cœur reste intacte et se met à jour normalement.
- Cette intégration réutilise le routeur déjà authentifié du cœur (`entry.runtime_data`).
- Installation : HACS, Dépôts personnalisés, URL de ce dépôt, catégorie Intégration. Puis
  Paramètres, Appareils et services, Ajouter une intégration, « Freebox RTS Shutters ».
